Authentication & Access Control

  • ✅ Implement Multi-Factor Authentication (MFA) for all user accounts.
  • ✅ Enforce Role-Based Access Control (RBAC) — deny access by default.
  • ✅ Use strong, unique session tokens; regenerate on login.
  • ✅ Implement account lockout after repeated failed login attempts.
  • ✅ Apply the principle of least privilege to all system accounts.

Data Protection

  • ✅ Enforce HTTPS/TLS 1.2+ on all communication channels.
  • ✅ Encrypt sensitive data at rest (passwords, PII, payment data).
  • ✅ Hash passwords using bcrypt or Argon2 — never store plaintext.
  • ✅ Use parameterised queries to prevent SQL injection.
  • ✅ Validate and sanitise all user inputs server-side.

Availability & Resilience

  • ✅ Implement rate limiting and request throttling.
  • ✅ Deploy a Web Application Firewall (WAF).
  • ✅ Set upload size limits and validate file types.
  • ✅ Monitor system resources and set up automated alerts.
  • ✅ Maintain regular database backups with offsite storage.

Auditing & Monitoring

  • ✅ Log all security-relevant events with timestamps and user IDs.
  • ✅ Use tamper-evident, write-once log storage.
  • ✅ Retain transaction receipts and digital evidence.
  • ✅ Implement real-time alerting for suspicious behaviour.
  • ✅ Conduct regular security code reviews and penetration testing.
